# Violence District — Build Planner

An interactive web-based build planner for **Violence District**, designed to help players customize and optimize Killer and Survivor loadouts, manage perks, and analyze unique character statistics and abilities in real time.

## Features
- **Role Switching:** Seamlessly toggle between Killer and Survivor loadout builders.
- **Dynamic Stats & Abilities:** Real-time calculation and display of character stats, base/pursuit speeds, intent radius, and unique powers (including *The Masked* mask mechanics).
- **Interactive Modals & Tooltips:** Advanced filtering system for perks, items, and accessories with detailed tooltips.
- **Responsive Dark UI:** Polished dark-themed interface tailored for gaming community standards.

## Built With
- **HTML5** & **CSS3** (Custom UI layout with Flexbox/Grid)
- **Vanilla JavaScript (ES6+)** for state management and DOM manipulation
- **GitHub Pages** for continuous hosting & deployment
